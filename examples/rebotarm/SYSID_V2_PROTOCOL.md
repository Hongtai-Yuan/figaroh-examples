# reBotArm SysID v2 采集与验收协议

## 目标

本协议用于获得可独立验证、可重复的动力学辨识数据。轨迹通过离线约束并不等于参数可靠；只有训练、独立验证和重复性验收全部通过后，参数才允许进入 URDF 或控制器。

## 已生成的离线轨迹

- `data/trajectories/sysid_train_v2.csv`：动态训练轨迹，seed 3101；
- `data/trajectories/sysid_validation_v2.csv`：独立动态验证轨迹，seed 9109；
- `data/trajectories/friction_j1_v2.csv` 至 `friction_j6_v2.csv`：逐轴双速度、双方向摩擦轨迹。

每个 CSV 都有同名 JSON，包含 CSV SHA-256、URDF SHA-256、位置/速度/加速度/jerk/名义力矩极值、300 Hz 驱动样条复查结果和随机种子。任何 CSV 修改都会导致实机采集器拒绝执行。

## 实机前置条件

1. `/dev/ttySTM32_ARM` 存在且当前用户可读写；
2. 机械臂周围无人、无障碍物；
3. 操作者在机械臂旁，能够使用急停；
4. 重新编译并启动包含加固后 action server 的 `dm_drive`；
5. 没有视觉任务、MPC 或其他程序同时控制机械臂；
6. 首次只运行动态训练轨迹，不连续批量执行；
7. 每次异常或测试结束后运行 `scripts/stop_arm.py` 并确认六轴状态为 0。

## 动态训练采集

```bash
cd /home/nuc001/ibvs-migration
source ros_ws/install/setup.bash

python3 third_party/figaroh-examples/examples/rebotarm/tools/record_dynamic_sysid.py \
  --trajectory third_party/figaroh-examples/examples/rebotarm/data/trajectories/sysid_train_v2.csv \
  --output third_party/figaroh-examples/examples/rebotarm/data/real/sysid_train_v2.csv \
  --output-rate 100
```

训练数据检查通过后，机械臂冷却并重新开始一次独立运行，再采集 validation。不能复制训练数据或从训练数据随机切分验证集。

## 摩擦采集

逐轴执行 `friction_j1_v2.csv` 至 `friction_j6_v2.csv`。训练和验证至少各采集一轮；验证轮可以执行相同命令轨迹，但必须是不同时间的真实反馈。

## 数据质量硬门槛

- CSV/JSON 完整且哈希匹配；
- 所有时间戳严格递增，重采样周期为 `0.01 s`；
- 非有限值数量为 0；
- 反馈跳变拒绝比例不高于 1%；
- 最大有效反馈间隔不高于 `0.03 s`；
- 实测位置始终在轨迹 JSON 的工作盒内；
- 实测速度和力矩没有触发在线监控；
- 起点和终点都返回前向安全中心；
- 训练与验证文件的采集时间和轨迹 SHA 不相同。

## 参数验收硬门槛

1. 回归矩阵保持满目标秩，缩放条件数目标低于 2000；
2. 物理约束求解成功，所有质量为正，伪惯量矩阵满足半正定要求；
3. 独立验证 RMSE 不高于：

   ```text
   [0.81, 0.81, 0.81, 0.21, 0.21, 0.21] N·m
   ```

4. 验证集必须相对原 URDF 改善，不能只降低训练误差；
5. 再独立采集一次重复性数据，主要可观测参数变化目标不超过 15%；
6. 残差不能继续明显依赖速度方向，否则必须加入/修正摩擦模型；
7. 第 3 关节验证失败时，完整模型继续判定为失败；
8. 未知绝对力矩比例时，只能把结果视为相对辨识；要写入最终 URDF，应增加已知质量和已知力臂的末端载荷实验。

## 部署规则

- 动态、摩擦、独立验证、重复性和物理一致性全部通过后，才允许导出新的 URDF；
- 导出的 URDF 必须保留来源数据哈希和验证报告；
- 新 URDF 先进行离线重放，再进行低增益静态保持测试；
- 任意验收失败时保留原 URDF，不用训练集上的候选参数控制真实机械臂。

## 2026-11-09 实机结果

本轮已经完成两次互相独立的 50 秒动态采集：

- 训练：`data/real/sysid_train_v2.csv`，5002 个 100 Hz 样本；
- 验证：`data/real/sysid_validation_v2.csv`，5003 个 100 Hz 样本；
- 两次采集均无反馈跳变拒绝，CSV 和采集元数据均保留哈希；
- 另采集了两次第 3 关节双向摩擦轨迹，用于定位完整刚体辨识失败的原因。

### 为什么没有把完整辨识结果写回 URDF

直接同时估计各连杆的质量、质心和惯量时，回归矩阵条件数约为 `9539`。虽然比旧数据约 `19120` 有改善，但仍明显病态。物理约束解在独立验证集上的总体误差没有优于原 URDF，且第 3 关节超过验收线。此时导出的单个质量或惯量会沿不可观测零空间大幅漂移；数值求解成功不代表参数真实。因此，本轮明确拒绝修改 URDF 的惯性参数。

第 3 关节单独摩擦实验得到约 `1.45 N·m` 的库仑摩擦，并在第二次实采中重复出现。这说明此前完整辨识把显著的换向摩擦错误分配给了惯性参数，是参数“不好用”的主要原因之一。

### 已通过的模型

最终采用分层模型：

1. 保留原 URDF 的刚体参数；
2. 使用已通过静态独立验证的重力比例（仅第 2 关节为 `0.697778`）；
3. 只在上述模型的力矩残差上拟合每轴粘性摩擦、平滑库仑摩擦和常值偏差；
4. 粘性和库仑系数增加非负约束；
5. 换向宽度和正则强度仅由训练数据的 5 秒分块交叉验证选择；
6. 参数固定后才在另一条实机轨迹上做一次最终验收。

可复现命令：

```bash
cd /home/nuc001/ibvs-migration/third_party/figaroh-examples/examples/rebotarm
/home/nuc001/ibvs-migration/.tools/miniforge3/envs/figaroh-dev/bin/python \
  tools/fit_validated_residual_dynamics.py \
  --train data/real/sysid_train_v2.csv \
  --validation data/real/sysid_validation_v2.csv
```

结果保存在 `results/validated_residual_dynamics_v2.json`。验收结果为：

| 指标 | 原模型 | 辨识后 |
|---|---:|---:|
| 独立验证总体 RMSE | 0.6260 N·m | 0.3337 N·m |
| 第 1 关节 RMSE | 0.3848 N·m | 0.1826 N·m |
| 第 2 关节 RMSE | 0.5814 N·m | 0.2815 N·m |
| 第 3 关节 RMSE | 1.3448 N·m | 0.7365 N·m |
| 第 4 关节 RMSE | 0.1709 N·m | 0.0682 N·m |
| 第 5 关节 RMSE | 0.1180 N·m | 0.0640 N·m |
| 第 6 关节 RMSE | 0.1175 N·m | 0.0673 N·m |

总体改善约 `46.7%`，六轴均低于预先声明的各轴误差门槛。JSON 中保存了输入文件 SHA-256、所有候选超参数、最终系数和逐项验收结论。

### 当前可用范围

这套结果已经是可靠的离线力矩预测模型，但状态是 `validated_not_hardware_deployed`。静态重力部分可继续用于已经测试过的拖拽重力补偿；动态摩擦前馈必须先做低增益、有限时长的实机安全测试，不能因为离线通过就直接全量开启。常值偏差可能混有未建模重力误差，拖拽控制中默认不启用。

由于尚未使用外部标定负载或力矩传感器，本结果不能声称得到了每个连杆绝对真实的质量和惯量。若目标是发布新的惯性 URDF，下一步必须加入已知质量/已知力臂实验，并采集第三条独立动态重复性轨迹。

## 2026-11-09 快速轨迹与六轴摩擦补充实验

为提高绕非承重轴（特别是关节 1、5、6）的惯性激励，又完成了以下实机实验：

- 关节 1、2、4、5、6 各两轮独立双向摩擦轨迹；关节 3 使用此前两轮；
- 两条不同中心姿态的 60 秒慢速动态轨迹；
- 两条 45 秒小幅快速动态轨迹；快速轨迹前三轴峰值速度约 `0.51 rad/s`、后三轴约 `0.70 rad/s`，峰值加速度分别约 `1.8` 和 `2.9 rad/s²`；
- 所有新采集反馈拒绝帧均为 0，轨迹均自动返回预定中心，结束后六电机状态均确认是 0（失能）。

快速轨迹证明了末端非承重关节必须依靠动态激励：独立验证中关节 5、6 的摩擦校正后力矩误差稳定在约 `0.077/0.062 N·m`。但是完整质量、质心、转动惯量的无先验求解仍未通过：总体独立验证比原模型差约 4%，第 3 关节约 `0.925 N·m`，并且正则化候选产生负质量或非正定惯量。因此这些候选明确拒绝写入 URDF。

六个关节的库仑摩擦在两轮独立恒速实验中均具有重复性，最终值为：

```text
[0.36742395, 0.57933857, 1.45064730,
 0.15633613, 0.15662388, 0.13844589] N·m
```

粘性系数在两轮之间不稳定，部分回归值为负，因此保守设为 0。上述六个可靠参数已经写入 `urdf/rebotarm.urdf` 各关节的标准 `<dynamics damping="0" friction="...">`，并同步写入统一配置。Pinocchio 重新加载后读回的六个数与验收结果完全一致。

这里的“写入 URDF”仅指通过独立验证的关节摩擦参数。质量、质心和转动惯量继续保留 CAD/原 URDF 值；在没有已知末端负载或外部力矩标尺时，不把跨姿态验证失败的惯性候选伪装成可靠结果。

## 2026-11-09 多轴重力姿态与重复验证

又增加了 12 个多轴训练姿态、8 个独立验证姿态和同一验证集合的第二次独立重复采集。每个姿态都从正、反两个方向到达，停稳后取中值，以抵消库仑摩擦；拟合质量/质心前还扣除了六轴独立摩擦实验得到的常值力矩偏差。

逐轴重力比例的重复结果：

- 关节 2：比例 `0.79413`，两次独立验证分别改善 `26.6%`、`27.8%`，`R²≈0.94`，稳定通过；
- 关节 3：比例约 `1.016`，两次改善均约 `6.2%`，拒绝；
- 关节 4：比例约 `0.877`，重力变化仅 `0.14 N·m` 且验证相关性为负，拒绝；
- 关节 5：比例约 `0.738`，两次改善 `21.9%`、`19.1%`，两次 `R²` 均低于 `0.5`，未达到重复性门槛；
- 关节 1、6：重力变化分别近似为零和 `0.00045 N·m`，物理上不可由静态重力可靠辨识。

`tools/fit_gravity_mass_com.py` 使用训练数据留一姿态交叉验证选择正则强度，并在两轮未参与调参的数据上检查质量、质心和误差。候选质量均为正、质心绝对坐标小于 `0.30 m`，每轴误差满足限制；但扣除已知力矩偏差后，相对原 URDF 的总体改善仅约 `13–14%`，低于预先声明的 `20%`。因此结果文件标记为 FAIL，脚本没有生成或覆盖质量/质心 URDF。

这次实验进一步表明：在无外部负载标尺的情况下，继续增加相似空载数据不能把很小的剩余信号可靠分配到各连杆质量、质心和惯量。若要解锁这些参数，必须增加已知质量与已知安装位置的负载差分实验，或使用外部六维力/力矩传感器。
